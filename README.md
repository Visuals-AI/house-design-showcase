# 全屋装修需求 · 设计沟通册

用于与设计师、装修公司沟通空间布局、家具设备、用电用水需求和装修效果的静态展示网站。

**[打开在线网站](https://visuals-ai.github.io/house-design-showcase/)**

## 网站内容

- 全屋空间、功能与设备分布图。
- AI + 3dsMAX 全屋功能效果巡游及模型下载入口。
- 客厅、餐厅、阳台、厨房、衣帽间、工作室、卧室、卫生间、连廊和玄关，共 12 个区域的需求。
- 现场实拍、3ds Max 渲染、AI 视觉参考及灵感视频预览。
- 家具与设备清单、各空间用电用水需求及全屋汇总。

## 资料说明

模型和效果图用于表达功能与设计意向，不代替施工图。所有尺寸以现场复尺、实物安装要求及最终确认图纸为准；列入配置不等于已经购买。风格、颜色和软装搭配在选购时进一步确认。

图片和商品链接仅用于设计沟通及选型参考，相关内容的权利归各自权利人所有。

## 内容维护与发布

源文档和网站生成工具维护在 [house-design](https://github.com/Visuals-AI/house-design) 仓库。本仓库保存生成后的 HTML、样式、脚本和图片，通过 `gh-pages` 分支发布至 GitHub Pages。

更新时应先修改源仓库中的 Markdown 或图片，再重新生成网站并发布。不要直接修改本仓库的生成页面，否则下次发布会覆盖改动。

网站不需要后端服务。3ds Max 模型等大型源文件不存放在本仓库，下载入口见网站巡游说明。
